# 03 - v1.2 - Localization

> Reach India's language base. Source: [docs/06-Design-System.md](../06-Design-System.md) localization, [docs/00-PRD.md](../00-PRD.md).

---

## Summary

Full i18n framework and the first languages: Hindi, Telugu, Tamil. Each language gets a localized personality, not just literal translation (per the Design System). AI chat mirrors the user's language. Optional regional verdicts.

## In scope

- i18n framework (string resources + locale switching).
- Hindi, Telugu, Tamil for all UI + verdict copy.
- AI chat responds in the user's language (Pollinations already supports this).
- Festival weather context (Diwali, Holi, Sankranti).
- Regional verdicts (e.g. auto-rickshaw, bike commute) behind locale.

## Build phases and sessions

### Phase 1 - Framework

- Session 1.2.1 - Extract all hardcoded strings to resources; locale picker in Settings. Outcome: language switch works for UI shell.
- Session 1.2.2 - Verdict copy localization in shared module (template strings keyed by locale). Outcome: verdicts speak the chosen language.

### Phase 2 - Languages

- Session 1.2.3 - Hindi pack + personality review. Outcome: full Hindi app.
- Session 1.2.4 - Telugu pack + idioms ("enda mandipotundi"). Outcome: full Telugu app.
- Session 1.2.5 - Tamil pack. Outcome: full Tamil app.

### Phase 3 - Context

- Session 1.2.6 - Festival calendar + contextual copy. Outcome: festival-aware briefs.
- Session 1.2.7 - AI language mirroring verified across the three languages. Outcome: chat answers in-language.

## Definition of Done

- App fully usable in English, Hindi, Telugu, Tamil.
- Verdicts and chat localized with natural idioms, not literal.

## Outcome for users

Ravi, Sneha, and Ramesh can use Kosmos in their own language - the unlock for mass India adoption.
