# 06 - v2.1 - Travel Overlay + Social

> Persona: Aisha (digital nomad). Source: prototype "Where should I go?" screen + [docs/14-Prototype-Spec.md](../14-Prototype-Spec.md) section 10.

---

## Summary

The Travel overlay (auto-activates when GPS moves > 100 km) with a destination + home split and a pack list, plus the "Where should I go?" recommender screen with multi-select filters. Adds sharing so users can spread Kosmos verdicts.

## In scope

- Travel overlay: destination + home weather split, trip-duration verdicts, pack list.
- Auto-activate > 100 km from home; revert on return.
- "Where should I go?" screen: vibe / good-for / distance / region filters over a destination list.
- Sharing: verdict-as-screenshot, copy text, WhatsApp share.

## Build phases and sessions

### Phase 1 - Travel overlay

- Session 2.1.1 - Detect > 100 km move; overlay state; revert logic. Outcome: travel mode auto-toggles.
- Session 2.1.2 - Home vs destination split + pack list. Outcome: traveler dashboard.

### Phase 2 - Where to go

- Session 2.1.3 - `TravelDestinationCard` + curated JSON destinations. Outcome: destination list.
- Session 2.1.4 - `TravelFilters` (vibe/audience/distance/region) multi-select + filtering. Outcome: working recommender.

### Phase 3 - Social

- Session 2.1.5 - Share verdict as image; copy to clipboard; WhatsApp intent. Outcome: shareable verdicts.

## Definition of Done

- Travel overlay activates on real travel; pack list + split work.
- Where-to-go filters return sensible destinations.
- Users can share a verdict in two taps.

## Outcome for users

Travelers get home + destination weather and packing help; everyone can share Kosmos - a viral loop.
