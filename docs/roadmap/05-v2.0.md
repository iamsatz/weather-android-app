# 05 - v2.0 - Mode System + Kosmos+

> The big one: the same brain serves different personas. Source: [docs/10-Master-Brief.md](../10-Master-Brief.md) section 5, prototype MODES.

---

## Summary

A mode configuration layer (which verdicts fire + threshold overrides + tone + UI density), a quick mode switcher, and three new modes: Employee, Family, Photographer. Plus commute advice, the Kosmos+ paywall, and read-aloud TTS as a premium feature.

## In scope

- Mode config layer + DataStore `user_mode`.
- Mode switcher in Settings (mode grid from prototype).
- Employee mode (7 work-day cards), Family mode (8 cards, stricter AQI/UV, child profiles), Photographer mode (golden/blue hour, fog, stars).
- Commute multi-select (Bike/Bus/Car/Walk) + commute line appended to rain/heat verdicts.
- Mode-aware customize cards (hidden-card sets per mode).
- Kosmos+ paywall (Play Billing): unlimited chat, all modes, voice, multi-location.

## Build phases and sessions

### Phase 1 - Mode architecture

- Session 2.0.1 - Mode config model (enabled verdicts, threshold overrides, tone, density) in shared module. Outcome: engine accepts a mode.
- Session 2.0.2 - `ModeCard` + `ModeGrid` + switcher in Settings; persist mode. Outcome: switch modes (Default works, others stubbed).

### Phase 2 - The modes

- Session 2.0.3 - Family mode: child profiles, stricter thresholds, school brief. Outcome: parent-focused cards.
- Session 2.0.4 - Employee mode: commute, lunch walk, screen breaks, gym window. Outcome: work-day cards.
- Session 2.0.5 - Photographer mode: golden/blue hour, fog, stargazing, lightning. Outcome: shoot-window cards.

### Phase 3 - Commute

- Session 2.0.6 - `CommuteChip` multi-select + `CommuteRepository`; append merged commute sentence to rain/heat verdicts. Outcome: commute-aware advice.

### Phase 4 - Kosmos+

- Session 2.0.7 - `PlanCard` + Kosmos+ screen; Play Billing integration. Outcome: subscription purchase flow.
- Session 2.0.8 - Gate premium features (unlimited chat, all modes, voice, multi-location). Outcome: free vs paid split.

## Definition of Done

- Pick one primary mode; UI + verdicts change accordingly.
- Commute advice appears on relevant verdicts.
- Kosmos+ purchasable; premium features gated.

## Outcome for users

One app that reshapes itself for parents, workers, and photographers - and the first revenue path.
