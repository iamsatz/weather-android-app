# 08 - v4.0+ — Pure weather platform (Long Tail)

> Kosmos is a **pure weather app**: fuse signals, return plain-English verdicts in-app. No fitness, calendar, or messaging bots.

---

## v4.0 — Multi-source weather brain

| Session | Shipped |
|---|---|
| **4.0.1** | `MultiSourceClient` — Open-Meteo + optional Tomorrow.io (`TOMORROW_API_KEY` in `local.properties`) |
| **4.0.2** | Multi-model confidence on rain/heat verdicts ("2 models agree" / "models split") |
| **4.0.3** | Wind/gust in Open-Meteo hourly + farmer spray, walk, gust verdicts |
| **4.0.4** | Hyper-local agent v2 grounded in fused numbers |
| **4.0.5** | IMD/cyclone curated alert stub (partnership-ready) |
| **4.0.6** | Pro health — migraine (pressure), asthma (AQI + humidity + pollen) |
| **4.0.7** | Verdict share as image card |

Outcome: Rain/heat/wind verdicts show fused confidence; farmer/travel modes use wind; hyper-local returns fused analysis.

## v5.0 — Weather platform (trimmed)

- **Voice in/out** — SpeechRecognizer in chat; TTS brief via `BriefReader`
- **Weather wallpaper** — condition gradient lock screen (Pro)
- **Radar layer** — RainViewer API preview screen
- **10-day + hourly UV polish** — Timeline Pro sections

**Removed:** Smart home (IFTTT/Home Assistant), B2B embed API.

---

## v6.0 — Weather depth (trimmed)

- **Weekly weather insights** — Sunday digest notification
- **Personal weather diary** — optional journal in Settings

**Removed:** Streaks, referrals, leaderboards, Telegram/WhatsApp bots.

## Explicit never-build list (Android)

- Google Fit / HealthKit

## Optional keys

```properties
# local.properties (repo root, not committed)
TOMORROW_API_KEY=your_key_here
```

Without a key, Kosmos runs on Open-Meteo only — fusion degrades gracefully.
