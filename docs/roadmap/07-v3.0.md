# 07 - v3.0 - Farmer Mode + Confidence + XL Widget

> The deep India play and the accuracy upgrade. Persona: Krishnamurthy. Source: [docs/10-Master-Brief.md](../10-Master-Brief.md) Farmer spec.

---

## Summary

Farmer mode replaces the entire verdict catalog with crop-specific advice (spray, harvest, sowing, pest, monsoon). Adds the Tomorrow.io confidence layer ("3 models agree" / "models split"), the Extra Large 4x4 widget, and longer-range forecasting.

## In scope

- Farmer mode: spray window, harvest readiness, sowing, pest pressure, stubble, monsoon onset.
- Farmer setup: crops, sowing date, plot location (separate from home GPS), language.
- Soil moisture + soil temperature from Open-Meteo; monsoon countdown widget.
- Tomorrow.io secondary source -> confidence indicators.
- XL 4x4 widget (insights + mini timeline).
- 10-day forecast, pollen, hourly UV (Pro).

## Build phases and sessions

### Phase 1 - Farmer mode

- Session 3.0.1 - Farmer verdict catalog in shared module (replacement set). Outcome: crop verdicts fire.
- Session 3.0.2 - Farmer setup flow (crops, sowing date, plot location). Outcome: personalized farmer profile.
- Session 3.0.3 - Soil moisture/temp data + monsoon onset logic + countdown. Outcome: monsoon + spray accuracy.
- Session 3.0.4 - Farmer UI: 7-day prominent, voice-first, bigger icons. Outcome: farmer-optimized layout.

### Phase 2 - Confidence

- Session 3.0.5 - `TomorrowClient` + agreement logic vs Open-Meteo. Outcome: confidence copy on rain.

### Phase 3 - XL widget + range

- Session 3.0.6 - XL 4x4 widget (insights + mini timeline). Outcome: largest widget.

## Definition of Done

- Farmer mode is a full, separate experience with real soil/monsoon data.
- Rain verdicts show confidence when two sources agree/disagree.
- XL widget renders.

## Outcome for users

Farmers get genuinely actionable crop timing; everyone gets more trustworthy rain calls.
