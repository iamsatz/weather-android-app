# 02 - v1.1 - Widgets + Alerts + Engagement

> Reach more surfaces and bring users back. Source: [docs/00-PRD.md](../00-PRD.md) section 9, [docs/12-Widgets.md](../12-Widgets.md).

---

## Summary

All widget sizes, the rain-alert notification (most-wanted alert), severe-weather push, and chat engagement limits with a Kosmos+ teaser. The widget is the product for most Android users, so this version is high-leverage.

## In scope

- Large (4x2) and Small (1x1) widgets.
- Widget verdict deep-links (tap a verdict -> that verdict in the app).
- Rain alert (60 min before) + severe weather push.
- Ask Kosmos: 5/day free limit + Kosmos+ badge (no billing yet).
- Lock-screen-style full alert.

## Build phases and sessions

### Phase 1 - Widgets (DONE)

- Session 1.1.1 - `WidgetHeader`, `WidgetVerdictRow`, `WidgetHourlyRow` Glance components. (done)
- Session 1.1.2 - Large 4x2 widget: header + top 4 verdicts + hourly strip. (done)
- Session 1.1.3 - Small 1x1 widget: temp + condition + top verdict. (done)
- Session 1.1.4 - Deep links: tapping a verdict opens app with insights expanded. (done)

### Phase 2 - Alerts (DONE)

- Session 1.1.5 - `AlertCheckWorker`: hourly check, rain ~60 min before. (done)
- Session 1.1.6 - Severe weather push (heat > 40°C, AQI > 200). (done)
- Session 1.1.7 - `RainAlertActivity` full-screen style + preview in Settings. (done)

### Phase 3 - Chat engagement (DONE)

- Session 1.1.8 - 5/day limit, counter in DataStore, Kosmos+ teaser subtitle + badge. (done)

## Definition of Done

- 3 widget sizes live and refreshing; deep links work.
- Rain + severe alerts fire correctly; quiet by default at night.
- Chat shows daily limit and Kosmos+ teaser.

## Outcome for users

Kosmos lives on the home screen and the lock screen, and proactively warns about rain - the habit-forming surfaces.
