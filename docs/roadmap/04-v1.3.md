# 04 - v1.3 - Accessibility / Elder Mode

> The first real "mode" - presentation, not new verdicts. Persona: Ramesh (67, Visakhapatnam).

---

## Summary

An Elder-friendly presentation layer: much bigger text, two-color high-contrast theme, voice-first readout, and a simplified home showing only the top 3 cards. This is the proving ground for the v2.0 mode system - it validates that one brain can drive very different UIs.

## In scope

- Elder mode toggle (presentation only; same 17 verdicts).
- Large type scale + high-contrast palette.
- Voice readout (TTS) of the day's brief.
- Simplified home: top 3 cards, no chat/timeline clutter.
- Bigger touch targets.

## Build phases and sessions

### Phase 1 - Presentation layer

- Session 1.3.1 - High-contrast theme + XL type scale variant. Outcome: a readable, bold theme.
- Session 1.3.2 - Elder home layout (top 3 cards, big hero, hidden extras). Outcome: simplified screen.

### Phase 2 - Voice

- Session 1.3.3 - TextToSpeech readout of brief; "Read aloud" button. Outcome: hear the day in English (and later local language).
- Session 1.3.4 - Settings entry to enable Elder mode + persist. Outcome: one-tap switch.

## Definition of Done

- Elder mode switches the whole UI to big/high-contrast/voice.
- Same verdicts, simplified to top 3.

## Outcome for users

Older users get a calm, legible, spoken weather companion - and we prove the mode architecture before building the full system.
